How the pass works

The code holds a link, not the farmer's details, so an ordinary phone camera opens it too — there is nothing to install at a gate.

Opening it shows that one farmer and nothing else, and only to staff or to the farmer it belongs to. A pass someone else photographs is worth nothing to them.
